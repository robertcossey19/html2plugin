MODEL REVIEW — SIGNAL PATH · CONTROLS · MEASUREMENTS · ESTIMATES

SIGNAL PATH (both styles, both modes). Nodal (DK-method) simulation solved per sample with Newton iteration in WebAssembly, 2x oversampled. Mic: 10468 input transformer (1200 ohm strap, 1+1:2+2 = 1:2 as in the Carnhill VTB9045 data; leakage inductance, winding capacitance, core saturation and hysteresis) → BA284 (A1, 3 BC184C stages, only at −80…−55) → BA283 (A2, 3 BC184C stages) → BA283 output amp (BC184C + 2N3055 class-A emitter follower, 18.5 dB feedback) → LO1166 output transformer into 600 ohm. Line: 31267 input transformer with the 1039 ohm tap chain, then A2 and the output stage. Gain is set exactly the way the unit does it: the EK20033 switch ladders (Rt / Rsu / series / shunt / pad) change the feedback and interstage networks of the real stages. There are no waveshapers, no static curves, no "transformer" high-pass + tanh anywhere. Saturation is where it is in the hardware: output transformer core first at low frequencies, then the output stage clips, then A2, then A1 when it is in the path.

GAIN (Classic). The 5 dB switch. Mic −80…−20 (13 positions), line +10…−20 (7 positions). Modelled gain at 1 kHz is within about 1 dB of the nominal step over the whole range (measured in the model: −80 → 80.6 dB, −20 → 20.7 dB).

MODERN — the Classic gain switch taken apart into its three physical effects. On the unit, turning the gain switch does three things at once: it changes the circuit (so the frequency/phase response changes), it changes how hard the stages and transformers are driven (saturation), and it changes the level. Modern runs the same simulations and separates them. CHARACTER = the frequency/phase response of switch position C: the exact circuit for that position, linearised about its operating point, scaled to the Drive position's gain. No distortion in this path. DRIVE = the saturation of switch position D: the full nonlinear circuit for D is run at the real signal level, and the same circuit linearised is run on the same signal; the difference between the two is exactly what D's nonlinearity adds (harmonics, intermodulation, compression) and nothing else. Output = Character path + that difference. With Character and Drive on the same position this is sample-identical to Classic (verified bit-for-bit). GAIN = clean level after the circuits, it can never add or remove distortion: preamp mode is calibrated as total gain like the unit (20…80 dB mic, −6…+24 dB line), Mastering mode is −24…+24 dB. Both Drive and Character are stepped like the switch they come from (13 mic / 7 line positions).

MASTERING MODE. For a finished track rather than a mic or line source, so the mic/line calibration does not apply. The track is taken at its true level: 0 dBFS at the input = +24 dBu at the output transformer of the selected circuit (the unit's nominal maximum line level), unity gain at 1 kHz. The track's own level is what drives the stages and transformers — a −1 dBFS master sits about 2 dB under the output stage's ceiling and well into the LO1166's low-frequency saturation, a −12 dBFS mix barely touches either. Classic: the gain switch selects the full nonlinear circuit for that position (its frequency/phase response and its saturation structure); it does not change loudness. Modern: the same split as preamp mode — Drive = saturation of position D, Character = EQ of position C, Gain = ±24 dB clean. With Character = Drive = the Classic position and Gain at 0 dB, Modern Mastering is sample-identical to Classic Mastering. Note what the physics says here: at the same output level the difference between two gain positions of a 1073 is small (sub-dB response differences, THD in the hundredths of a percent up to a few percent at 20 Hz for the A1+A2 positions). That is the unit, not a limitation of the model.

MEASURED IN THE MODEL (offline render, 48 kHz, 2x). Classic, mic −50, +20 dBu out, 1 kHz: THD 0.0005 %. Mic −80, +20 dBu out, 20 Hz: 0.53 %. Line 0, +20 dBu out: 0.05–0.06 %. Output stage alone −0.59 dB @20 kHz, −2.57 dB @40 kHz. Mastering (both styles, track at −1 dBFS): unity 0.00 dB @1 kHz at every position; 1 kHz THD 0.006 % (−50/−80) to 0.008 % (−20); 20 Hz THD 3.8–4.2 % (LO1166 core at +23 dBu — the published THD spec stops at 50 Hz, where the model reads 0.05 %); 20 kHz −0.57 dB (−50), −0.62 dB (−80), −0.76 dB (−20). Classic Mastering vs Modern Mastering with Character = Drive = the same position and Gain 0 dB: sample-identical (max difference 0). True stereo: a left-only input leaves the right output at −172 dBFS, and the left output is bit-identical whether the right channel is silent or carrying signal; mono mode sums L+R into one chain. Hardware spec sheet: THD <0.07 % @+20 dBu, ±0.5 dB 20 Hz–20 kHz, −3 dB @40 kHz, >+26 dBu into 600 ohm. Modern separation checks: Character −80 with Drive −20 follows the −80 response (20 Hz −0.123 dB, 20 kHz −0.620 dB, same as Classic −80 linearised: −0.123 / −0.620); Character −20 with Drive −80 follows the −20 response (20 kHz −0.758 vs −0.758). Drive −20 with Character −80 at +20 dBu: THD 0.0043 %, 2nd harmonic −87.68 dB vs Classic −20: 0.0043 %, −87.68 dB. Drive −80 with Character −20 at +20 dBu: 1 kHz 0.0033 % vs 0.0033 % Classic; 20 Hz 0.51 % vs 0.53 % (the 0.3 dB difference in fundamental level between the two positions' LF response). Character ≠ Drive at small signal adds 0.0001 % THD. Gain +12 dB clean: THD unchanged (0.00053 %). Modern Mastering: 0.00 dB @1 kHz, −1 dBFS peaks into Drive −20: 0.008 %, into Drive −80 at 20 Hz: 3.6 %. Mono mode (L+R summed into one chain) and Stereo (two chains) verified in both styles. CPU: a 3-stage Drive position (−80…−55) with a different Character in stereo at 2x can exceed one core; the engine then drops to 1x ECO for monitoring (export always renders 2x). At 1x ECO the trapezoidal warp pulls 20 kHz down about 5 dB at 48 kHz.

ESTIMATES (not measured against a unit). 31267 line transformer leakage inductance / winding capacitance (tuned to hit the published ±0.5 dB / −3 dB @40 kHz response), LO1166 leakage, 10468 primary inductance (1.22 H from the Carnhill design guide), output stage feedback 18.5 dB vs the 15 dB often quoted, transformer crosstalk (synthetic −60 dB HF-weighted path, no coupling measurement exists for it), SPICE device parameters for BC184C / 2N3055 from datasheets. Nothing in this model has been compared against a physical 1073 — the numbers above are the model vs the published spec, not model vs hardware.
