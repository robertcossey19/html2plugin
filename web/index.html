0 One-time setup ▶
  1. Open github.com → Settings → Developer settings → Fine-grained tokens → Generate.
  2. Repository access: Only select repositories → the repo above.
  3. Permissions: Contents: Read and write, Actions: Read-only (Metadata is added automatically). Nothing else.
  4. Paste it here. Click Test connection.

    Downloads: VST3 installer → Cubase. AU installer → Logic Pro / GarageBand. Both → one .pkg that installs both into /Library/Audio/Plug-Ins.
    Builds are ad-hoc signed: the first open may need right-click → Open, or xattr -dr com.apple.quarantine on the .pkg. Every release also carries REPORT.md (which knobs were bound, measured output vs the browser version) and SHA256SUMS.txt.
    If a plugin sounds like a straight wire, read ~/Library/Logs/html2plugin/<name>.log.
