    Downloads: VST3 installer → Cubase. AU installer → Logic Pro / GarageBand. Both → one .pkg that installs both into /Library/Audio/Plug-Ins.
    Each release's notes carry a Signing line: Developer ID + notarized opens like any Mac installer; ad-hoc means no Apple certificate yet (see SIGNING.md): the .pkg itself needs one approval (right-click → Open, or System Settings → Privacy & Security → Open Anyway on macOS 15) and then the installer does the rest — it strips quarantine, re-signs the bundles and resets the AU cache, so no Terminal. Every release also carries REPORT.md (which knobs were bound, measured output vs the browser version) and SHA256SUMS.txt.
    If a plugin sounds like a straight wire, read ~/Library/Logs/html2plugin/<name>.log.
