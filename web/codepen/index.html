3 Installing on your Mac

    
    
      
  1. Download Both in one .pkg (or VST3-only for Cubase, AU-only for Logic).
    2. 
      
  2. In Downloads, right-click the .pkg → Open, then Open on the warning. macOS 15: double-click, get refused, then System Settings → Privacy & Security → Open Anyway, and open it again. Once per plugin.
    3. 
      
  3. Continue, Install, password. The installer strips quarantine, re-signs the bundles on your Mac and resets the AU cache. No Terminal.
    4. 
      
  4. Open Logic or Cubase. If Logic had a failed copy listed before, Plug-in Manager → Reset & Rescan Selection once.
    5. 
    

    
Don't drag the .vst3.zip / .component.zip into the plug-in folders: that keeps the quarantine flag on and brings the Terminal fix back. Always the .pkg. The warning in step 2 only disappears with an Apple Developer ID (see SIGNING.md).

  


  

    Reads use GitHub's public API without a token: 60 requests an hour from your network. If that runs out mid-build, the page switches to tag watching through jsDelivr and the release link; the build itself is unaffected.
    If a plugin sounds like a straight wire, read ~/Library/Logs/html2plugin/<name>.log.
